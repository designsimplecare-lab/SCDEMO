# Starter note templates (for Daniel to correct)

Drafted 5 Nov 2026 at Ani's request ("draft starter version"). Daniel has not sent his own templates yet. These are placeholders so the
Insert menu does something real in the demo. **Daniel replaces or corrects them before any doctor uses them.**

## How they behave in the demo
- **Where:** Insert in the note toolbar (chart Version 2). Each part lands under its own heading: Subjective, Objective, Assessment or Plan.
- **Typing over:** words the doctor must fill sit in [brackets], and the first bracket is selected, so he types straight over it.
- **Signing:** asks first while any bracket is left (REQ-CH-07; OQ-16 is still open: block or ask).
- **Nothing clinical is chosen for him:** medicines, doses, findings and diagnoses are brackets.

## The six templates

**Follow-up visit**
- Subjective: Follow-up of [problem] from [date]. Since then: [better / same / worse]. Treatment: [taking as prescribed, side effects].
- Objective: [Findings or home readings].
- Assessment: [Problem], [improving / stable / not improved].
- Plan: [Continue / change treatment]. Follow up in [time frame], sooner if [warning signs].

**Result follow-up**
- Subjective: Follow-up of [test] ordered on [date] for [reason]. Current symptoms: [none / describe].
- Objective: [Test]: [value] [units] (reference [range]), [date].
- Assessment: [Interpretation of the result].
- Plan: Result reviewed with the patient. [Repeat test / treatment / referral]. Next step: [when].

**Prescription renewal**
- Subjective: Requesting renewal of [medicine, strength, directions]. Taking as prescribed: [yes / no]. Side effects: [none / describe].
- Objective: [Home readings or last labs, with dates].
- Assessment: [Condition], [stable] on current treatment.
- Plan: Renewed [medicine] for [duration], [repeats]. Monitoring due: [labs, date]. Next review: [date].

**Urinary symptoms**
- Subjective: Painful urination for [days]; frequency, urgency [yes / no]. Blood in urine [yes / no]. Fever, flank pain, vaginal
  discharge [denies / describe]. Possibly pregnant [no / yes]. Previous urinary infections [none / when].
- Objective: Virtual visit, no examination.
- Assessment: [Uncomplicated cystitis, suspected].
- Plan: [Treatment, dose, duration]. Urine culture [ordered / not needed]. Seek care if fever, flank pain, vomiting, or no better in 48 hours.

**Sick note visit**
- Subjective: Off [work / school] since [date] with [symptoms].
- Objective: Virtual visit, no examination.
- Assessment: [Acute illness]; expected to return [date].
- Plan: Work or school note for [dates], without a diagnosis. Return sooner if [warning signs].

**Normal virtual exam** (Objective only)
- Virtual visit by [phone / video]. Speaking in full sentences, no audible distress. [Video: appears well, alert and oriented].
  Home readings: [BP, heart rate, temperature, if available].
